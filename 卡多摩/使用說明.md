## 程式概述

本程式用於將卡多摩嬰童館的採購單格式轉換為出貨單格式，自動完成以下作業：

- 驗證原始檔案格式是否符合規範
- 根據檔案名稱自動識別門市資訊
- 透過條碼對照表查詢產品編號
- 自動帶入產品單價
- 產生標準化的出貨單Excel檔案

### 適用對象
- 每日需要重複性轉換訂單檔案的作業人員
- 處理卡多摩門市採購單轉出貨單的行政人員

## 原始檔欄位特徵

### 必填欄位
原始檔案（採購單）必須包含以下欄位，否則無法轉換：

| 欄位名稱 | 資料類型 | 說明 |
|---------|---------|------|
| 倉別 | 文字 | 倉庫代碼，如 K009 |
| 商品條碼 | 文字(13碼數字) | EAN-13條碼 |
| 商品名稱 | 文字 | 產品名稱 |
| 進貨數量 | 數字 | 訂購數量 |
| 採購單號 | 文字 | 採購單編號 |

### 選填欄位
| 欄位名稱 | 資料類型 | 說明 |
|---------|---------|------|
| 計價數量 | 數字 | 計價用數量 |
| 商品備註 | 文字 | 產品備註 |
| 出貨註記 | 文字 | 出貨狀態 |
| 開單人員 | 文字 | 開單人 |
| 採購單備註 | 文字 | 單據備註 |

### 檔案格式驗證規則

1. **標題列識別**：程式會自動搜尋包含「倉別」字樣的列作為標題列
2. **倉別一致性**：同一檔案只能包含單一倉別
3. **條碼格式**：必須為13碼數字
4. **資料完整性**：商品條碼和商品名稱不可為空

### 原始檔命名規範
建議使用以下格式命名，以便自動識別日期：
```
YYYYMMDD_採購單[倉別代碼] [店名].xlsx
範例：20260330_採購單K009 三重重陽店.xlsx
```

## 執行方法

### 方法一：命令列執行

```bash
# 基本用法
python order_converter.py 原始檔.xlsx

# 指定輸出檔名
python order_converter.py 原始檔.xlsx -o 輸出檔.xlsx

# 指定對照表資料目錄
python order_converter.py 原始檔.xlsx -d ./data
```

### 方法二：批次處理腳本

建立 `batch_convert.bat`（Windows）或 `batch_convert.sh`（Mac/Linux）：

```bash
#!/bin/bash
# 批次轉換範例

for file in 採購單*.xlsx; do
    echo "正在轉換: $file"
    python order_converter.py "$file"
done

echo "批次轉換完成！"
```

### 方法三：Python程式呼叫

```python
from order_converter import OrderConverter

# 建立轉換器實例
converter = OrderConverter('./data')

# 執行轉換
converter.convert('原始檔.xlsx', '輸出檔.xlsx')
```

## 對照表維護

### 通路資料維護

檔案：`通路資料.json`

```json
{
  "stores": [
    {
      "店名": "卡多摩嬰童-三重重陽",
      "電話": "02-2986-1107",
      "地址": "新北市三重區重陽路二段9號"
    }
  ],
  "keyword_mapping": {
    "三重重陽": "卡多摩嬰童-三重重陽"
  },
  "warehouse_mapping": {
    "K009": "卡多摩嬰童-三重重陽"
  }
}
```

**新增門市步驟**：
1. 在 `stores` 陣列中加入新店資訊
2. 在 `keyword_mapping` 中加入店名關鍵字對應
3. 在 `warehouse_mapping` 中加入倉別對應

### 條碼對照表維護

## 常見問題

### Q1: 轉換時出現「無法找到標題列」錯誤

**原因**：原始檔中找不到「倉別」欄位

**解決方法**：
- 確認原始檔格式正確
- 檢查標題列是否包含「倉別」字樣
- 確認Excel檔案沒有密碼保護

### Q2: 產品編號顯示為空白

**原因**：條碼對照表中找不到對應條碼

**解決方法**：
1. 檢查原始檔中的條碼是否正確
2. 在 `條碼對照表.json` 中新增對應關係
3. 重新執行轉換

### Q3: 門市資訊顯示為「未知門市」

**原因**：無法從倉別代碼識別門市

**解決方法**：
1. 確認倉別代碼是否正確
2. 在 `通路資料.json` 的 `warehouse_mapping` 中加入對應關係
3. 重新執行轉換

### Q4: 單價顯示為0

**原因**：單價對照表中找不到對應品號

**解決方法**：
1. 檢查產品編號是否正確
2. 在 `單價對照表.json` 中加入對應單價
3. 重新執行轉換

### Q5: 如何批次轉換多個檔案？

**解答**：使用批次處理腳本（見「執行方法」章節）
