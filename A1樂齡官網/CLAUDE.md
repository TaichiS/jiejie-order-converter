## 轉換規則

### 展開品項
- 每筆訂單的 `貨號`、`購買品項`、`商品單價`、`數量` 均以 `\n` 分隔
- 每個品項獨立一列輸出
- **價格為 0 的品項跳過**（這些是組合包的子品項，不單獨列出）

### 組合包處理
- 有組合品號（`F` 開頭）時，只保留組合那一列
- 組合包內附贈的子品項（價格=0）一律不輸出
- 若客人**單點**個別品項（價格>0），則正常列出

### 地址解析
輸入格式：`郵遞區號\n城市 行政區\n街道地址\n姓名`

解析規則：
- 第 1 行（郵遞區號）→ 跳過
- 第 2 行（城市+行政區）→ 去除空格合併（`台北市 大安區` → `台北市大安區`）
- 第 3 行（街道）→ 保留
- 第 4 行（姓名）→ 跳過
- 輸出：城市行政區 + 街道（如 `台北市大安區新生南路二段18號5樓之一`）

注意事項：
- **行政區在前的格式**：若第 2 行順序為「行政區 城市」（如 `三芝區 新北市`），需自動對調為「城市行政區」（`新北市三芝區`）
- **街道已含城市地址**：若第 3 行已包含完整城市+行政區前綴（如 `新北市中和區 中正路…`），直接使用第 3 行，不重複拼接第 2 行
- **英文地址**：遇到全英文地址直接保留，不做拆解

### 折扣處理
- `折扣金額` 可能多筆以 `\n` 分隔 → 加總後放在同訂單第一列
- 同訂單後續列的 `商品折扣金額` 填 0

### 商品名稱
- 優先從 `品號資料.csv` 以 `商品貨號` 查詢 `品名`
- 查不到時，清理 `購買品項` 欄位（去除 `捷捷樂齡食品-` 前綴）

### 特殊品項
- 黑貓貨到付款手續費（無貨號）→ 貨號填 `F59900003`
- 原始資料中手續費有時價格為 0（贈送/免收），仍跳過該列；但**只要是貨到付款訂單，一律在最後補上 F59900003 / 30元**（不論原始資料是否已含手續費品項）
- `JJ-SR-C-4-1` → `D51000004 / C04麻香牛肉燉飯`（惜福品，品號資料表未收錄）
- `JJ-SR-G8P` → `F30100073 / 粥飯好滿足8件組 (不含牛)`（品號資料表未收錄）

## 每次操作步驟

### 整理訂單
1. 上傳後台匯出的訂單檔（`MMDD.xlsx`）及 `品號資料.csv`（如有更新）
2. 下指令：「依照 0227 檔案跟品號資料把 MMDD 做成新檔案（另存）」
3. 輸出整理好的 `MMDD.xlsx` 存入資料夾

### 製作黑貓托運單
1. 上傳整理後的 `MMDD.xlsx`
2. 下指令：「請幫我把 MMDD 做成黑貓托運單依照黑貓印製托運單檔案」
3. 輸出 `MMDD黑貓.csv` 存入資料夾
