# AI官網 訂單整理工作說明

## 專案說明
AI官網定期將後台匯出的訂單整理成標準格式，分拆為黑貓宅配與全家超商兩個檔案供出貨使用。

---

## 資料夾結構

```
AI官網/
├── MMDD.xlsx             → 後台匯出原始訂單
├── 黑貓0227.xlsx          → 黑貓格式參考檔
├── 全家0227.xlsx          → 全家格式參考檔
├── 品號資料.csv            → 商品品號對照表
├── 加購品.csv             → 加購品折扣對照表
├── MMDD黑貓vN.xlsx        → 黑貓宅配輸出檔
└── MMDD全家vN.xlsx        → 全家超商輸出檔
```

## 輸入檔欄位（後台匯出）

| 欄位 | 說明 |
|------|------|
| 訂單號碼 | 如 `#20260201025122856` |
| 收件人 | 收件人姓名 |
| 完整地址 | 含「台灣」前綴與郵遞區號 |
| 收件人電話號碼 | 可能含 `+886` 國碼 |
| 商品貨號 | 可能為非標準品號（G/N 開頭），需對照 CODE_MAP |
| 商品名稱 | 完整品名 |
| 數量 | 以份數計 |
| 商品結帳價 | 原始份數價格 |
| 全家服務編號 / 7-11 店號 | 有值 → 全家超商；空白 → 黑貓宅配 |
| 加購品類型 | `主商品加購品` → 加購品；空白 → 一般商品 |

## 欄位轉換規則

### 一般商品（非加購品）

**D 系列（冷凍粥飯）：**
- `數量` = 原始數量 × 品號資料.包數
- `商品結帳價` = 品號資料.商品結帳價（每包單價）

**F 系列（組合包）：**
- `數量` 不變
- `商品結帳價` = 品號資料.商品結帳價

### 加購品（加購品類型 = 主商品加購品）

- `數量` = 原始數量 × 品號資料.包數（同樣展開）
- `商品結帳價` = 加購品.csv.金額 ÷ 品號資料.包數（**用原價**，非加購優惠價）
- `加購折扣` = 加購品.csv.折扣（新增欄位，放在商品折扣金額後）
- 加購折扣反映每份的優惠折扣金額

## 地址解析

- 去除「台灣」前綴
- 去除郵遞區號（開頭數字）
- 拼接城市 + 行政區 + 街道（無空格）
- 電話：去除 `+886` 國碼，補回 `0` 前綴，截至 10 碼

## 運費處理

- 原始輸入檔含 `運費` 欄位，若某訂單的運費 > 0，在該訂單品項列**最後**補上一列：
  - 商品貨號：`F59900001`
  - 商品名稱：`運費`
  - 數量：`1`
  - 商品結帳價：運費金額
- 運費為 0 或空白的訂單不新增列
- 黑貓與全家檔案均適用此規則

## 每次操作步驟

1. 上傳後台匯出的 `MMDD.xlsx`
2. 下指令：「請把 MMDD 依照黑貓0227 跟全家0227 分出2個檔案並參考品號資料跟加購品」
3. 檢查運費欄位，有運費的訂單在最後補 F59900001 運費列
4. 輸出 `MMDD黑貓vN.xlsx` 與 `MMDD全家vN.xlsx`
5. 依黑貓格式輸出 `MMDD黑貓托運單.csv`（一訂單一列）
