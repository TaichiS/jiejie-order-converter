# 品號資料庫說明

> 建立日期：2026-04-10
> 適用版本：品號統一資料庫整合後（含 ProductRepository）

---

## 一、為什麼要整合？

整合前，品號參考資料散落在多個 CSV/JSON：

| 檔案 | 供應通路 |
|------|---------|
| `reference/品號資料.csv` | 蝦皮、婦幼展、樂齡網 |
| `A1樂齡官網/品號資料.csv` | 樂齡官網 |
| `捷捷寶寶粥官網/品號資料.csv` | 捷捷官網 |
| `優迪通路/品號資料.csv` | 優迪通路 |
| `卡多摩/條碼對照表.json` | 卡多摩（條碼查品號） |
| `卡多摩/單價對照表.json` | 卡多摩（品號查單價） |

整合後，所有資料集中在 SQLite（未來可切換 Supabase），各通路可**獨立定價**。

---

## 二、資料庫 Schema

### `products`（品號主表）

| 欄位 | 型別 | 說明 |
|------|------|------|
| `sku` | TEXT (PK) | 品號，如 `D50100001` |
| `name` | TEXT | 主品名，如 `0-1純米泥` |
| `category` | TEXT | 類別，如 `冷凍粥飯` |
| `quantity` | INTEGER | 份數 |
| `pack_size` | INTEGER | 包數（nullable） |
| `unit_price` | REAL | 份數價格（nullable） |
| `erp_source` | TEXT | ERP 來源，如 `鼎新` |

### `product_aliases`（別名表）

同一品號可有多個別名（如「2-M義大利麵-100克」= `D50500001` 的別名）。

| 欄位 | 說明 |
|------|------|
| `sku` | FK → products.sku |
| `alias` | 別名品名（sku+alias 組合唯一） |

### `product_barcodes`（條碼表）

| 欄位 | 說明 |
|------|------|
| `sku` | FK → products.sku |
| `barcode` | EAN 條碼，全表唯一 |

### `channel_prices`（通路定價表）

同一品號在不同通路可有不同售價。

| 欄位 | 說明 |
|------|------|
| `sku` | FK → products.sku |
| `channel` | 通路代號（見下表） |
| `price` | 商品結帳價（sku+channel 組合唯一） |

**通路代號對照：**

| 代號 | 通路名稱 |
|------|---------|
| `shopee` | 蝦皮 |
| `a1baby` | 婦幼展 |
| `leage` | 樂齡網 |
| `a1leage` | 樂齡官網 |
| `jjofficial` | 捷捷官網 |
| `yodee` | 優迪通路 |
| `kadomo` | 卡多摩 |

## 三、ProductRepository 用法

所有品號查詢都透過 `app/repositories/product_repo.py` 的 `ProductRepository`，**不要直接操作 ORM 或讀 CSV**。

### 基本使用

```python
from app import create_app, db
app = create_app()
with app.app_context():
    from app.repositories.product_repo import ProductRepository
    repo = ProductRepository()
```

### 載入通路品號（Converter 使用）

```python
# 回傳 (product_map, code_map)
# product_map: 品名（含別名）→ row_dict
# code_map: 代碼前綴（如 "1-08"）→ row_dict
product_map, code_map = repo.load_channel("shopee")

row = product_map.get("0-1純米泥")
# row 格式與舊 CSV DictReader 一致：
# {"品號": "D50100001", "品名": "0-1純米泥", "類別": "冷凍粥飯",
#  "份數": "1", "包數": "4", "份數價格": "140", "商品結帳價": "35.0", "來源": "鼎新"}
```

### 查詢通路條碼（卡多摩用）

```python
# 回傳 {barcode: sku}，只包含該通路有定價的品號
barcodes = repo.load_barcodes("kadomo")
sku = barcodes.get("4710586220018")  # → "D50100001"
```

### 查詢單一品號定價

```python
price = repo.get_price("D50100001", "kadomo")  # → 26.0
price = repo.get_price("D50100001", "shopee")  # → 35.0
```

## 四、直接查詢 DB（Shell / 腳本）

### 查某品號在所有通路的定價

```bash
uv run python3 -c "
from app import create_app
app = create_app()
with app.app_context():
    from app.models import ChannelPrice
    for cp in ChannelPrice.query.filter_by(sku='D50100001').all():
        print(cp.channel, cp.price)
"
```

### 查某條碼對應哪個品號

```bash
uv run python3 -c "
from app import create_app
app = create_app()
with app.app_context():
    from app.models import ProductBarcode
    bc = ProductBarcode.query.filter_by(barcode='4710586220018').first()
    print(bc.sku if bc else '找不到')
"
```

### 查某通路所有品號（含定價）

```bash
uv run python3 -c "
from app import create_app
app = create_app()
with app.app_context():
    from app.models import ChannelPrice
    for cp in ChannelPrice.query.filter_by(channel='kadomo').order_by(ChannelPrice.sku).all():
        print(cp.sku, cp.price)
"
```

## 五、新增 / 修改品號資料

### 新增品號

```python
from app import create_app, db
from app.models import Product, ChannelPrice

app = create_app()
with app.app_context():
    # 新增主品號
    prod = Product(
        sku="D50100099",
        name="新品名",
        category="冷凍粥飯",
        quantity=1,
        pack_size=4,
        unit_price=140,
        erp_source="鼎新",
    )
    db.session.add(prod)

    # 新增通路定價
    db.session.add(ChannelPrice(sku="D50100099", channel="shopee", price=35.0))
    db.session.add(ChannelPrice(sku="D50100099", channel="kadomo", price=26.0))

    db.session.commit()
```

### 新增條碼

```python
from app.models import ProductBarcode

db.session.add(ProductBarcode(sku="D50100001", barcode="4710586220099"))
db.session.commit()
```

### 修改通路定價

```python
from app.models import ChannelPrice

cp = ChannelPrice.query.filter_by(sku="D50100001", channel="shopee").first()
cp.price = 40.0
db.session.commit()
```

### 新增別名

```python
from app.models import ProductAlias

db.session.add(ProductAlias(sku="D50500001", alias="2-M義大利麵-100克"))
db.session.commit()
```

## 六、重新匯入資料（從 CSV 重建）

若 CSV 資料有大量更新，可重新執行匯入腳本（upsert，不會重複）：

```bash
cd /Users/lung/.../訂單格式轉換系統
uv run python3 scripts/migrate_reference_data.py
```

腳本會自動處理：
- 主行（有商品結帳價）→ upsert Product + ChannelPrice
- 別名行（商品結帳價空白）→ upsert ProductAlias
- 卡多摩條碼 JSON → product_barcodes
- 卡多摩單價 JSON → channel_prices（channel='kadomo'）

## 七、切換到 Supabase

只需設定環境變數，不需改任何程式碼：

```bash
# 設定 Supabase 的 PostgreSQL 連線字串
export DATABASE_URL=postgresql://postgres.[project-ref]:[password]@aws-0-[region].pooler.supabase.com:5432/postgres

# 安裝 PostgreSQL driver（只需一次）
uv add psycopg2-binary

# 啟動系統（自動使用 Supabase）
uv run python3 run.py
```

切換後需在 Supabase 建立相同 schema：
```bash
uv run python3 -c "from app import create_app; app = create_app(); print('Schema 建立完成')"
```

然後重新執行匯入腳本，將資料寫入 Supabase。

## 八、注意事項

1. **`routes.py` 的 `/search_product` 和 `/alias` 路由**仍直接讀寫 CSV（技術債），尚未遷移至 Repository。CSV 檔案目前仍在，功能正常；若日後移除 CSV，需一併遷移這兩個路由。

2. **卡多摩的 `通路資料.json`**（門市 / 倉別對照）不在 DB 中管理，維持 JSON 格式，路徑：`卡多摩/通路資料.json`。

3. **新增 DB Schema 欄位**時，`db.create_all()` 不會 ALTER 已存在的表，需手動執行：
   ```bash
   uv run python3 -c "
   import sqlite3
   conn = sqlite3.connect('data/conversion.db')
   conn.execute('ALTER TABLE products ADD COLUMN new_col TEXT')
   conn.commit()
   "
   ```
