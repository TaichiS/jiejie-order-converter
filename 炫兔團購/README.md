# 【炫兔團購】訂單轉換程式

## 📋 程式說明

本程式用於將「炫兔團購」原始訂單格式（`0402-0404.xlsx`）轉換為「全家v1」欄位配置。

## 🎯 核心功能

- **數量轉換**：原始數量 × 包數 = 目標數量
- **價格轉換**：原始價格 ÷ 包數 = 目標價格  
- **貨號對照**：簡碼（如 2-01）→ 完整品號（如 D50500004）
- **贈品過濾**：自動排除滿額贈品（小燈箱、滴雞精等）
- **名稱清理**：移除「團購限定B|」前綴

## 📁 檔案結構

```
├── convert_orders.py      # 主程式

```

## 🚀 快速開始

### 1. 安裝必要套件

```bash
pip install pandas openpyxl
```

### 2. 準備檔案

將以下檔案放在同一目錄：
- `0402-0404.xlsx` - 原始訂單檔案
- `品號資料_方案B(炫兔團).csv` - 品號對照表

### 3. 執行程式

```bash
python convert_orders.py
```

### 4. 查看結果

轉換後的檔案會儲存在 `output/` 目錄：
- Excel 格式（.xlsx）
- CSV 格式（.csv，UTF-8 BOM 編碼）

## 📊 轉換邏輯說明

### 數量轉換規則

| 商品類型 | 原始數量 | 包數 | 目標數量 | 計算方式 |
|---------|---------|------|---------|---------|
| 米泥 (0-x系列) | 1 | 4 | 4 | 1 × 4 |
| 小寶寶粥 (1-x系列) | 1 | 4 | 4 | 1 × 4 |
| 大寶寶粥 150g/200g | 1 | 2 | 2 | 1 × 2 |
| 燴料/燉飯 (2-x系列) | 1 | 2 | 2 | 1 × 2 |
| 水餃/饅頭 (後元系列) | 1 | 1 | 1 | 1 × 1 |

### 價格轉換規則

| 商品類型 | 原始價格 | 包數 | 目標價格 | 計算方式 |
|---------|---------|------|---------|---------|
| 大寶寶粥 200g | 150 | 2 | 75.0 | 150 ÷ 2 |
| 燴料 | 109 | 2 | 54.5 | 109 ÷ 2 |
| 燉飯 | 150 | 2 | 75.0 | 150 ÷ 2 |

### 貨號對照範例

| 原始貨號 | 完整品號 | 商品名稱 |
|---------|---------|---------|
| 2-01 | D50500004 | 2-1醬燒什錦豬肉 |
| 0-01 | D50100001 | 0-1純米泥 |
| 0-17 | D50100017 | 0-17雞肉米泥 |

## 🔍 常見問題

### Q1: 執行時出現「FileNotFoundError」？

請確認以下檔案存在於程式目錄：
- `0402-0404.xlsx`
- `品號資料_方案B(炫兔團).csv`

### Q2: CSV 檔案中文顯示亂碼？

本程式輸出的 CSV 使用 `UTF-8 BOM` 編碼，可直接在 Excel 中開啟。
若仍有亂碼，請在 Excel 中使用「資料 → 從文字/CSV」匯入，並選擇 UTF-8 編碼。

### Q3: 如何保留贈品資料？

請修改 `convert_order_row()` 函數，將以下程式碼註解掉：

```python
# 排除贈品（貨號為空）
# if pd.isna(original_code) or original_code == '':
#     return None
```

### Q4: 某些商品貨號無法對照？

請檢查 `品號資料_方案B(炫兔團).csv` 是否包含該商品。
若為新品項，請手動加入品號資料表，程式會自動讀取。
